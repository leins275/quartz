# Правила
1. Пока заметка не готова - она не переносится из волта в другие. Возможен только перенос ресурсов, после переноса ресурс из источника отправляется в архив.
# Папки как статусы
Одна заметка может одновременно лежать только в одной папке. В целом, это ложится в концепцию статусов. Потому что у каждой заметки в один момент времени может быть только одно состояние. 
## 01 Projects
Заметки над которыми работаю. Посты, идеи итд.
## 02 Areas
Области внимания. Сейчас использую для плагина баз, которого очень не хватало.

Теги используются как средство поиска заметок общей темы, папки - как статусы. Я показываю базу отфильтрованных заметок в виде карточек, на карточках показываю теги и папку, где лежит заметка, и сортирую по названию папки

При этом, в качестве областей могу также использоваться zero links.
## 03 Resources
Заметки над которыми работа не завершена, но которые не входят в projects. К примеру заметки с цитатами из книг.

Также в контексте постов, готовые посты становятся ресурсами.
## 04 Archives
По умолчанию всё тут в одной куче. В начале года всё старое собирается в папку прошлого года
# Теги как темы
Теги гораздо больше подходят для распределения заметок по темам. У одной заметки может быть несколько тем, и в случае с папками это никак не поддержать.

Теги и расширения файлов - это отображение сущности. Сам тег отображает сущность заметки. Использую иерархию тегов, если нужна большая детализация.
# Входящие
Все входящие падают просто в корень волта. Это максимально естественное поведение для обсидиана - не нужно ничего настраивать, плюс ко всему дает дополнительный контроль над ситуацией.
