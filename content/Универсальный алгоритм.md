# 250906
Этот алгоритм может быть применен к решению любой проблемы.
## 1. Изучи, что уже есть
Сначала необходимо ознакомиться со всеми известными способами решения проблемы.
## 2. Редуцируй к нулю
Нужно взять все лучшие практики из известных, и отбросить почти все, оставив минимальный скелет.

Этот минимальный селет и будет являться отправной точкой рабочего решения.
## 3. Адаптируйся 
Скорее всего, изначальный скелет решения не будет устраивать. Поэтому со временем решение нужно дополнять решениями конкретных болей. Решения можно брать из лучших практик или изобретать самостоятельно, не так важно. Главное - идти от своего запроса и решать конкретные проблемы.

# 240602
1. Анализ. Провести исследование всех доступных подходов.
2. Упрощение. Выделить минимум принципов из общедоступных подходов. Собрать простейшую систему
3. Адаптация. Исходя из конкретных потребностей по улучшению системы внедрять новые подходы для решения конкретных задач.
