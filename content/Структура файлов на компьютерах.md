# Windows main PC
```mermaid
mindmap
	root((PC storage))
		System(System C:\)
			Only system & temporary files
			files1(Files)
				Desktop
				Downloads
				WSL
			Backed up with windows image (win7)
		Storage(Storage D:\)
			All important data is stored here
			Backed up with powershell script
			files2(Files)	
				Git
				GDrive
				Vaults
		Games(Games E:\)
			Storage specificly for steam games data
			No backup
```
