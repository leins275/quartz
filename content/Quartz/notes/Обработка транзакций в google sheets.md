# Обработка транзакций из выгрузки Papara

1. При помощи следующих формул сделать все значения валидными числами
```
=SUBSTITUTE(C34, ".", "")
=SUBSTITUTE(D34, ",", ".")
```

> [!warning] Форматирование
> Важно, форматирование вносит дополнительные символы, которые мешают работе формул. Использовать форматирование только после шага 2

1. Скопировать все значения из формул в новый столбец
